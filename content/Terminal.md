
<code>Ctrl+L</code> 可以清屏，但保留歷史  
<code>Cmd+K</code> 清屏並清除歷史  
<code>Ctrl+U</code> 清除整行  

<details>
  <summary>如何創建一個新的md文件？</summary>
  <p><code>touch newfile.md</code> 用於創建新文件；<code>mkdir new_folder</code> 用於創建新文件夾。</p>
</details><br>


<details>
  <summary>如何通過終端在文件中插入新文本？</summary>

```bash
echo "新內容" > file.md  # > 會覆蓋原有內容，檔案中只剩 "新內容"。
echo "新內容" >> file.md  # >> 會在檔案最後新增一行，不刪掉原內容。 
```
</details><br>
